# 🛡️ SOC Analyst

A practical cybersecurity learning and reference repository focused on **SOC (Security Operations Center) Analyst** skills.

This repository contains my learning notes, hands-on labs, investigations, scripts, and useful references as I learn and practice cybersecurity.

## 🎯 Purpose

The purpose of this repository is to document what I learn through practical exercises and create a useful reference for myself and for others interested in cybersecurity and SOC analysis.

The content and organization of the repository will evolve as I continue learning.

## 🧪 Learning Approach

The focus is on **learning by doing**.

I will document the concepts, labs, investigations, tools, scripts, and lessons learned throughout my learning process.

## ⚠️ Disclaimer

This repository is for educational and defensive cybersecurity purposes.

Only perform security testing and investigations on systems, networks, and data that you own or have explicit authorization to use.
